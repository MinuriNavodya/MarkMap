# MarkMap – Past Paper Score Tracker & Revision Planner

MarkMap is an offline mobile app built with React Native that helps students
track their past paper scores, identify weak topics, and plan their revision
effectively.

## Features
- Browse a local library of past papers with search and filters (subject, year, attempted/not attempted)
- View detailed paper information and attempt history
- Log attempts with score, time taken, notes, and struggled topics
- Weak topics ranked automatically to show what to revise next
- Weekly revision planner to schedule papers and tick them off
- Score history to see progress over time
- Works fully offline using locally stored data (no public APIs or online databases)

## Tech Stack
- React Native (Expo)
- React Navigation (stack and bottom tabs)
- AsyncStorage / expo-sqlite for local storage
- Local JSON dataset for seed data
